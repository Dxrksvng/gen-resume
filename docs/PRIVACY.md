# Privacy and data boundary

The current Gen Resume application runs locally. Users provide their own documents, and the local workflow creates temporary extraction files, draft PDFs, and review records on the same machine. Users should review and remove local outputs according to their needs.

This public repository contains no candidate documents, generated resumes, source code, account database, or hosted resume-processing endpoint. Do not open an issue containing a resume, identity document, phone number, email address, or job application details.

A hosted commercial version would require a separate privacy notice, consent flow, retention/deletion policy, access controls, and security review before launch. None of those hosted-service guarantees are claimed here.
